# Review Log

One entry per `/app-review` run. Newest first. Each entry is the finding
list at the time, each item's status, and any new rule it produced in
`review-rules.md`. A future review reads this before starting so it can
say "still open from last time" instead of rediscovering the same thing,
and skips anything marked `wontfix` without re-flagging it.

Status values: `open`, `fixed`, `wontfix` (with reason), `deferred`
(user chose to postpone, not rejected).
